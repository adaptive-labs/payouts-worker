# Getting started with Payouts Worker

Welcome to `payouts-worker`. This guide gets you from zero to a running local copy.

## Prerequisites

- Docker
- Access to the adaptive-labs GitHub org

## Run locally

```bash
git clone git@github.com:adaptive-labs/payouts-worker.git
cd payouts-worker && make dev
```

## First task

Pick a `good-first-issue` and ship a small change end to end.
